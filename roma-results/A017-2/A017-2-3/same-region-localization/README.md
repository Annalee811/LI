# A017-2-3 同一区域定位与统一尺寸独立RGB

四期齐全。区域定位仍以原始T1为标准；结构关系使用T1/T4、T3/T4、T2/T4。其中T2/T3的直接RoMa可靠点不足；粗区域假设来自明确记录的跨期结构关系，不能称为该段神经逐点配准成功。输出标为候选定位，尚未通过完整路线一致性核对，需人工确认。额外RoMa区域模型与最终定位的差异中位数/95百分位（T1像素）：T2/T4 14.16/32.34（不是人工误差）。未参与构建的结构路线对共同范围的差异中位数/95百分位（T1像素）：T1/T2 8.08/19.24。路线未达到5像素核对规则：T1_to_T2，须重点目视复核。

细框标出全部实际存在时期均可观察到的最大横向几何矩形，独立裁剪图均为2517×512像素。保留原色及实际根系、土层变化；只作整体等比缩放、旋转和平移，RGB单次采样，无局部弹性拉伸。T1裁剪像素与原始T1对应矩形逐像素相同。
