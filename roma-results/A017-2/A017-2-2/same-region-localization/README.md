# A017-2-2 同一区域定位与统一尺寸独立RGB

四期齐全。区域定位仍以原始T1为标准；结构关系使用T1/T4、T3/T4、T1/T2。未参与构建的结构路线对共同范围的差异中位数/95百分位（T1像素）：T1/T3 1.90/4.34；T2/T3 1.47/3.04；T2/T4 3.93/8.96。

细框标出全部实际存在时期均可观察到的最大横向几何矩形，独立裁剪图均为2102×558像素。保留原色及实际根系、土层变化；只作整体等比缩放、旋转和平移，RGB单次采样，无局部弹性拉伸。T1裁剪像素与原始T1对应矩形逐像素相同。

自动结构定位不是逐条根的身份确认或新生、生长、死亡分类。共同几何视野不等于全部点可靠配准；点误差、区域稳定性和不同路线差异分别记录。条件空间分块验证依赖筛选后的描述子对应点，不能当作人工TRE或独立真实精度。没有人工标志点，真实TRE未评估。输出像素尺度和600 DPI不会增加原始拍摄细节。ZIP只包含5张PNG。过程、脚本和审计数据独立保存在analysis-scripts，未放入图片ZIP。
