# 0353-2-LB3 同一区域定位与统一尺寸裁剪

四期齐全。以原始T1坐标和尺度为基准，用细框标出四期都可观察到的最大横向几何矩形。四张独立RGB裁剪图均为2542×1407像素，保存原色与实际根系、土层变化；仅作整体等比缩放、旋转和平移，单次采样，无局部弹性拉伸。

使用T1/T3、T3/T4、T1/T2结构关系确定共同范围。另外三条独立区域路线差异中位数分别为1.45、1.48、2.64个T1像素。局部自动点验证仍可有约3–7个T1像素的中位差异，未以局部弹性变形消除。

这是自动区域定位，不是逐条根身份确认，也不是新生、生长或死亡分类。区域稳定性与局部点误差分别检查，较大的点误差未被标为3像素验证通过。没有人工标志点，真实TRE未评估；输出像素尺度和600 DPI不会增加原始拍摄细节。ZIP只包含5张PNG图片。审计数值与可重跑脚本独立保存在仓库analysis-scripts中。
