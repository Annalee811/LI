# 时序局部图：新生与根尖延伸同时展示 V64

本图仅更换 V44（V43时序头100轮实验）保存结果的局部展示窗口，不重新训练、不推理、不更改参考类别或模型预测，不重算性能指标，也不使用上传16的新逐根编号替换旧实验参考。

- 新窗口：原生坐标 `[1440,120,1824,504]`，384×384像素；四期、参考和三个模型使用完全相同坐标。
- T1为蓝色基础根；T2–T4绿色为新出现/新生段，金色为根尖延伸段，紫色为持续段。
- 参考图上的N/E箭头定位最大可见新生/延伸类别连通域中的实际像素。箭头只帮助观察参考位置，没有给任何模型补色。
- 底行分类图背景为白色；原生类别栅格直接用最近邻放大，无膨胀、根宽调整或类别平滑。
- 字体Times New Roman Bold、黑色，TIFF为RGB、6600×3660、600dpi。

## 窗口选择与用途

原256×256测试窗口并非每个后期都含参考延伸类别。为满足本次“新生、延伸都体现”的展示要求，本次仅依据参考标注，扫描256、320、384像素窗口，要求T2/T3/T4每期两类均至少60像素，排除旧窗口重叠；按六项类别像素数的对数覆盖分数（含窗口大小惩罚）选择。没有按三个模型的预测准确性挑窗口。

这是定性说明窗口，包含原空间分区的重叠区域，不能称为独立留出测试窗口。原指标表、ROC、混淆矩阵和损失图均保留，未因窗口变化改变。参考仍是旧版经过U-Net修订的时序参考，不是独立的外部人工验证。

参考类别像素数（非根条数）：

| 时期 | 新生段 | 根尖延伸段 |
|---|---:|---:|
| T2 | 5740 | 468 |
| T3 | 2085 | 164 |
| T4 | 99 | 108 |

T4两类范围相对较小，按真实保存结果显示，未扩宽或补画。T1不强行添加新生/延伸类别。

`verification.json`保存全部输入文件SHA256、裁剪/面板位置、原生类别计数、箭头实际像素坐标和输出TIFF尺寸/DPI校验。`ROI_selection.json`记录新旧窗口和原空间分区重叠情况。旧V44图仍保留。
