# 四期逐根结构复核初稿 V52

默认加载用户上传的 root_annotation_progress (10).json，四期上半幅原图。
原有 mask、color、temporal、viability 四层逐像素保持不变；新结构标注独立存储。
所有根编号、跨期关联、交叉连接、分叉及根尖均为待人工复核的自动候选。
候选轨迹含短碎段，不代表已经确认的生物学整根数量；边界端点单独标识。

使用：下载 annotate.html 后用 Chrome 或 Edge 打开。首次需联网读取固定版本的匹配原图；
也可点击“选择本地原图”选择四张匹配 PNG，再恢复含结构信息的 JSON。
按 T1～T4 切换。点击根段可改号、并入同一根或拆分；点击点位可选两臂连接、改归属、移动、删除。
对应区域的四期原始 RGB 同时显示。跨期同一根采用相同编号，并单独点击确认跨期对应。
原时序类别与逐根编号是两个层次：已有根可以包含持续段及末端延伸段。

完成后点击“保存全部进度 JSON”；也可“保存可编辑网页”。编辑仅保留在浏览器内存，需下载保存。
恢复导出的 JSON 会恢复结构和像素标注，导出的 HTML 可重新打开继续编辑。
旧链接中固定 commit 的版本保留；交付分支上的原编辑器路径已更新为本版。

结构位于 JSON 的 root_structure_annotation：每期 segments、nodes、单值 owner_map_rle，
及 cross_period_links。交叉中心单一归属仅覆盖原根掩膜内的结构身份，不改写时序像素类别。
节点连接为臂的一对一配对；点位均保留待复核/已修改/人工确认状态。
本次不修改正在运行的 V51 训练，也不把初稿直接作为已确认训练真值。
