## 使用

下载 annotate.html 后用桌面 Chrome/Edge 打开。首次原图读取需联网，或选择完全匹配的原始PNG。若在旧版又有新修改，先保存JSON；恢复旧JSON会按该文件还原，不会自动把本补标套到更新的修改上。

新页面顶部“截图左侧区域 · 四期补标初稿”：选择候选，点“定位并对照四期”。橙色虚线编号框表示本次待复核候选。可以确认当前补标、撤回为未定义、继续改号/母根、撤销、保存完整JSON及可编辑HTML。撤回不会删除根线，而是保留整个四期候选供重新定义。

原V62任意位置切开、精细选段、分出和归属编号工具保留。
