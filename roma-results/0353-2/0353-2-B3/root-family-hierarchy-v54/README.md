# 四期母根与侧根标注复核 V54

输入为 (10).json。mask、color、temporal、viability 四层原像素保持不变。
根的稳定内部身份 root_id 与可编辑显示编号分开保存。
母根0001；已有侧根0001-1、0001-2；新生侧根0001-N1、0001-N2。
侧根编号在后期持续、延伸时保留，N后缀不消失。更高级侧根如0001-1-N1。
母根及其全部后代在家族显示视图中同色，各自独立编号；时序类别色另行切换。

亲缘候选依据主轴两臂贯通、侧根从单侧终止接出、没有反侧贯通等几何证据。
四臂交叉不直接当作分叉；竞争母根、疑似交叉和年龄证据冲突保留未定。
利用同母根的连接位置及侧根走向，补接9组跨期断裂的侧根候选身份。
该稿全部待用户复核，不是经独立验证的生物学根系亲缘真值。

下载annotate.html后用Chrome/Edge打开。首次联网读取固定版本原图；也可选择匹配本地原图。
先点选侧根，在左侧“母根与侧根编号”填写母根，点已有侧根或新生侧根按钮。
改母根显示编号会同步四期及子根前缀，家族成员按钮便于逐根复核。
错误亲缘可设为独立母根，误拆段可合并，误连段可拆分；编号禁止重复，父子关系禁止循环。
修改后保存全部进度JSON或保存可编辑网页，下载保存后才能保留本地修改。
两种保存方式都能恢复继续编辑；升级V53进度时保留原母根记录，冲突不强行消解。

结构JSON的root_track_hierarchy存储label、parent_root_id、family_root_id、branch_kind。
每期segments存储相同信息，cross_period_links延续稳定的内部身份及显示编号。
同色属于显示层，不修改根宽、边界或原时序类别。不修改模型权重或训练任务。
