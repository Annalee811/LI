## 已复现的原因
旧pathBetween55只允许从起点沿已有连接路径走到终点；两条被误合并到同号、实际不连通的根，恰好不满足前提，因此会报“两端之间没有已确认的连续路径”。
在本次上传中发现95个正式根号-时期组合有多个连通段。连通性不足可能来自遮挡、旧切口或误合并，不表示95处都标错。cut_failure_diagnosis.json保存实际图结构和失败端点。
旧界面把错误写到隐藏状态框，随后用过期提示覆盖侧栏。本轮错误会显示在当前操作面板，并明确指出可以用不依赖连通路径的点选分离。

## 使用
下载annotate.html后用Chrome/Edge打开，已内置上传15，无须重新恢复旧稿。首次读取已有固定RGB地址需联网，也可选择匹配本地PNG。
1. 先在原图选择要修改的根。
2. 点击“点选要分出的部分”。默认按所点走向预选，多点可增减；粉色只是预览。
3. 相距分开的误并根，可选“所点连接块”；相连交叉范围过大，改选“只选这一段”，连续点击加入所需部分。
4. 确认分出粉色部分。分出后仍未定义，可用已有根号、母根侧根号或确认后的N-新根号加入体系。
5. 此分离默认只改当前期；其他时期保留原有身份。原号仍有其他部分时继续保留；不会随意覆盖其他时期的人工归属。
6. 如需在单段内部截取，下面“两点分开”仍可用；两端不通时不会伪造路径，会显示说明并引导改用点选分离。
可以撤销、保存JSON和可编辑HTML。未确认预览不会改数据，切换时期自动取消预览；保存预览页后重开不会残留隐藏编号的界面状态。

## 数据范围
点选分离只改变所选原有段的root_id，并移除直接跨越原根与分出根的旧节点连接。原线坐标、宽度、前景像素、时序像素类别和单像素owner索引不变。新候选不自动判新生，正式编号由用户定义。
“两点内部截取”是原有分段功能，确认时可分割段坐标列表和owner段索引，但不删除前景像素。
U-只是内部保存标识，不在原图显示为正式生物根号。自动选路仅为预览，仍应由用户核对。
source/build.py、detach.js为修复实现；source/diagnose.mjs和source/verify.mjs为真实浏览器诊断及验证；工程根/workspace/LI。
