# 四期逐根编号与编辑修复 V53

输入为 (10).json，原有四期像素标签、根宽和边界保持不变。
结构初稿重新关联整根身份：持续段和根尖延伸段继承前期根编号，
新出现的侧根单独编号，之后持续或延伸时沿用该编号。
无法可靠匹配的碎段保留临时编号，需人工复核，不自动认定为新生。
存在很强前期几何对应但时序颜色冲突时，保留同根候选并显示冲突提示，不自动改写颜色。

使用：下载 annotate.html 后用 Chrome/Edge 打开，首次需联网载入固定原图，
也可选择匹配的本地原图。点击根后在图上方输入编号（如0001），点击应用，四期同步。
“合并另一段为同一根”：先选第一段并点击此按钮，再点击另一段，四期轨迹同步并入同一编号。
列表默认按整根分组，取消勾选可查看单段。T1～T4切换后沿用所选根身份，显示各期匹配情况。
“改时序颜色／画笔”可编辑原像素标签；“移动点位”可拖动根尖、交叉或分叉点。
当前段或本期改号仍保留在左侧，按钮已明确范围。
修改完成后保存全部进度JSON或保存可编辑网页，下载保存后才能保留本地修改。
恢复JSON和重新打开保存的HTML都可继续编辑。

实际复现并修复：V52中切换编辑工具未退出平移，导致画布事件被平移捕获；
状态/错误提示隐藏在折叠区。V53切换编辑工具时退出平移，增加显眼编辑入口和始终可见状态提示。
