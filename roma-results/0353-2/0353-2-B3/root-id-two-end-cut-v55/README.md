# 根编号编辑与两端断开 V55

初始标注文件与V54逐字节相同。本轮只修改交互，不重新生成标注，不训练模型。
修复两个编号输入框不同步的问题；待应用输入在刷新时保留，点应用或Enter后立即生效。
输入已用编号表示归入同一根，四期同步。不同根只需调整顺序时可交换同级同类型编号。
母根及侧根编号沿用V54层级规则，亲缘候选仍须用户复核。

两端断开：先选根，点“选择断开的两端”，在根上先后点起点、终点，预览蓝色中间段。
中间段身份选择：
- 母根本体／续用指定根编号：输入0001，中间段并入0001本体。
- 已有侧根：输入母根0001，自动登记0001-1、0001-2等独立侧根，家族同色。
- 新生侧根：输入母根0001，自动登记0001-N1、0001-N2，后期沿用N编号。
- 暂不归属：自动注册独立待复核编号，之后可以改号或指定母根。
母根号可填在断开面板，也可使用之前实际输入的母根框。侧根模式也支持二级母根0001-1。
若要续用已有完整侧根编号，选“本体／续号”并填0001-N1，不会重新分配侧根号。

确认后不删根像素：仅断开图结构，登记中间段身份与断开端点。原时序像素类别保持不变。
默认尝试同步其它时期：仅同原根身份、端点和走向可靠对应者同步，共用一个编号；不可靠者保持原状。
可取消同步，仅处理本期。编辑、归入母根和侧根操作可撤销。
选中根后手工补画的新前景像素自动继承该根归属；像素撤销同时恢复归属。
已有交叉像素保留其原有唯一归属，补画不会自动抢占另一根的身份。

下载annotate.html，用Chrome/Edge打开。首次联网读取固定原图，也可选择对应本地PNG。
修改完成点保存进度JSON或保存可编辑网页，重新打开后可继续编辑。
本轮保留旧文件、旧版本链接和模型训练结果。所有自动亲缘及跨期同步候选仍待人工复核。
