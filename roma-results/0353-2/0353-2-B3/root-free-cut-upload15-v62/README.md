# 任意切开并分出根段 V62

内置用户上传 `root_annotation_progress (15).json`，未预先更改任何人工定义、像素层、根段轨迹或像素归属。

下载 annotate.html 后，用桌面 Chrome 或 Edge 打开。首次读取原始 RGB 需联网；也可导入完全匹配的本地原图。若已在旧版继续编辑，先保存旧版 JSON，再在本版恢复该 JSON。

## 操作

1. 点“① 点选切口”，在根线内部任意位置或端点点击。可选一处或多处，不需要两点间有连续路径；再点同处取消。
2. 交叉处核对下拉列表的目标根段，避免切错另一根。点击位置吸附到所选根段最近的已有轨迹点。
3. 点“确认切开 → ② 选择分出部分”。切开只改变当前期结构连接，原编号暂时不变。
4. 逐段点选要独立出去的部分（粉色预览，可多选、取消）；太短或交叉处难以命中时，可以使用根段列表选取，再点“确认分出粉色部分”。新部分保持未定义。
5. 为分出的部分定义已有编号、母根侧根编号，或经人工确认的新根编号。保存进度 JSON／可编辑网页。

只想分出一个已有整段，直接选根再点“② 分出切开的部分”。操作支持撤销；切口预览在取消、换期或恢复文件时作废。实际切开／分出后必须保存进度。

## 保真与边界

- 未进行模型训练，也未自动重新识别、补画或编号。
- 任意点切开可把原来的一个内部根段拆成独立可选的小段。每个原始轨迹点仍被保留，每个根像素仍只有一个归属。
- 不擦除二值根系像素，不改原图宽度、根系宽度或时序像素类别。像素所属的结构段索引可在切开后更新。
- 端点切开移除涉及该段端部的结构连接；交叉处其他根段的连接保留。
- 默认仅当前期，不自动沿四期传播，不把未定义候选宣称为新生根。
- 这些测试验证编辑行为与数据保存，不证明候选根的生物归属准确性，需人工复核。
