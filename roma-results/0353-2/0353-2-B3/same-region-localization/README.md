# 0353-2-B3 同一区域定位与统一尺寸裁剪

四期齐全。以原始T1坐标和尺度为基准，用细框标出四期都可观察到的最大横向几何矩形。四张独立RGB裁剪图均为2541×738像素，保存原色与实际根系、土层变化；仅作整体等比缩放、旋转和平移，单次采样，无局部弹性拉伸。

- [下载定位图与四张独立RGB图](0353-2-B3_same_region_map_and_four_RGB.zip)

三组相邻对应的自动点误差中位数均低于3个T1像素；另外三条独立区域路线差异中位数为1.07、2.57、3.80个T1像素。四期取景上下偏移较大，因此共同横向区域较窄。

这是自动区域定位，不是逐条根身份确认，也不是新生、生长或死亡分类。区域稳定性与局部点误差分别检查，较大的点误差未被标为3像素验证通过。没有人工标志点，真实TRE未评估；输出像素尺度和600 DPI不会增加原始拍摄细节。ZIP只包含5张PNG图片。审计数值与可重跑脚本独立保存在仓库analysis-scripts中。
