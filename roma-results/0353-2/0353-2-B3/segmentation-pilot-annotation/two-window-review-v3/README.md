# 0353-2-B3：两组四期标注复核版3

本包仅包含 `B3_A0_C0` 和 `B3_A0_C1`，每组 T1、T2、T3、T4，共8张图。先用这8张检查根系边界、粗细、遗漏和对应关系，再决定其他图的标注方案。

解压后直接用 Chrome 或 Edge 打开 **annotate.html**，图片和这8张标注均已内置，不必选择文件夹，也不需要联网。若系统把网页作为文本预览，请先保存到电脑再用浏览器打开。

## 查看与修改

- T1 的所有已标根都是已有基线根，统一显示蓝色；T1 不标新生、生长或持续。
- 后期可对应的根使用同窗编号；紫色表示暂定持续可见，黄色表示暂定新增延伸段。蓝色后期段为变化状态未判定，不能读成新生根。
- “根的来源批次”与“变化状态”分别保存。来源不明确的根保留未定；没有可靠跨期对应的段使用各期独立编号，不能按编号强行连接。
- 在“只高亮本窗根编号”输入编号，再点“查看本编号的四期对照”。编号只在同一个窗口内比较。未标出不代表死亡。
- 可关闭覆盖层看原图，也可调透明度、缩放及笔刷宽度。细根建议从1像素笔刷开始。Ctrl+Z / ⌘Z 撤销一笔。
- **修改后点“保存全部修改（项目JSON）”**，确认文件已下载。下次打开网页后载入这个JSON恢复修改；关闭前不要只依赖页面仍开着。
- 整图复核标签的导出另需实际复核者与整图确认。未完成复核也可以随时保存项目JSON。

## 本版边界

这是供你修改的首轮描画，细根完整性、像素边界、估计粗细与交叉处身份仍需逐图核对。没有把水滴圆弧、反光边缘或土壤纹理的自动描线沿用为根，也没有把完全遮挡的区段直接接成根。部分低对比度段仍可能漏标或偏移。

后期首次清楚显露不等于生物学新生；变暗、褐变、遮挡和一次未观察到均不能证明死亡。本包没有据此确认死亡，也没有宣称完成新生或死亡定量。所有图的整图人工复核状态均为未完成；生成来源保存在项目和逐图元数据中。

**不能把这版直接作为独立人工真值或据此填写 Precision、Recall、Dice、IoU、根长R²和RMSE。** 软件检查只验证显示、编辑、保存和数据一致性，不表示根系识别准确率。

原图为448×448 PNG，原始字节和RGB像素保持不变。对照综合图和覆盖图为单独输出，不代替原图。掩膜0=已确认背景、64=尚未复核、128=不确定、255=根；未描画的64不能自动当背景。根系来源、时序、颜色、存活属性、物体类别和编号另层保存。
