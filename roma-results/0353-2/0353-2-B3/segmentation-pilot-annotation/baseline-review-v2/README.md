# T1基线与补根修订版2

打开 annotate.html 即可修改，原图60张完整内置，原始像素和颜色保持不变。

本轮重点重描 B3_A0_C0 的四期示范，T1补画左侧可辨认的细根延续段、修正下部部分根段位置，并按可见范围断开遮挡。其余56张仅撤回部分短碎片/水滴亮边标记及不可靠的时序判断，尚未逐根完成重描，不是完整精标结果。仍可能漏根或误标，不能直接视作完整人工真值。

T1所有可见根都是已有基线根：来源批次=1，变化状态=未判定；T1不标新生、延伸或持续。后期根的“首次观察批次”和“本期变化状态”独立保存。例如T1已有根在T2可以持续；T2首次观察的根在T3也可以持续，但来源仍为T2。首次观察不是证明生物学出生。

默认综合层：T1已有根统一蓝色，后期紫色持续、绿色首次观察候选、黄色延伸；来源不明确的根仍保留未确定。可切换“根的来源批次”单独查看T1来源是否保留；不要把所有紫色持续根都视为T1根。

“物体分类”独立区分根、水滴、土壤、其他非根背景和不确定。仅部分区域有物体预标注，其余为未标注；水滴圈是限制在湿润区域内的圆形提议，尚未逐滴确认。根段优先，完全遮挡处不补画。物体层不作为已经验证的六分类真值。

用根系画笔补根；用水滴、土壤、其他背景按钮纠正类别。鼠标移到像素上可查看来源批次、状态和局部根编号。根编号和交叉处连接关系仍需核对，不能直接当作已验证生物学身份。表观宽度单位为原始像素，无毫米标尺。

Ctrl+Z撤销最近一笔。修改后点“保存全部修改（项目JSON）”，下次打开时载入该JSON；刷新前先保存。支持载入上版项目，保留已有根掩膜；T1时序自动纠正为已有基线。图像均待人员复核，勾选整图复核前应检查漏根和宽度，不能只看已画的线。

保存项目不要求完成整图。已复核标签ZIP另外导出主掩膜、颜色、时序、存活、来源批次、物体类别和局部编号；本轮没有真实人工复核标签、没有模型训练或Precision/Recall/Dice/IoU指标。
