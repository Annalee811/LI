# 0353-2-B3：四期完整裁剪拼接RGB分别标注

T1、T2、T3、T4 各一张完整RGB，分别标注，切换时期时可保留同一局部位置。不是把四期拼成一张，也不再让你先按训练小图分开标。每张保持已有结果的2541×1867像素与原色；图内原有24像素白色分隔带不是图像数据，禁止画根。

## 先保全旧页面的8张标注

**不要关闭或刷新仍有笔画的旧页面，也不要清理360压缩软件的临时目录。单独复制旧annotate.html不会保存内存里的笔画。** 云端无法直接打开你的 `file:///C:/...` 地址，当前包还没有收到你的实际8张标注。

1. 打开本包 **先保全旧标注.html**，点击“复制备份代码”。
2. 切回仍显示你标注结果的旧页面，按F12，在 Console／控制台粘贴代码并按Enter。
3. 旧页面右上角出现绿色保存按钮。点击，保存所有已有标注为一个JSON；确认文件确实已下载，再考虑关闭旧页面。
4. 打开新版 **annotate.html**，在“导入旧标注／恢复大图项目JSON”选择这个备份。
5. 看导入数量与冲突提示，选择“定位旧小图”逐张核对。导入后再点“保存全部标注JSON”，把完整图项目另存一份。旧备份也请保留，或上传给我核对。

备份代码只在旧页面本机运行，不请求网络、不刷新页面、不清除笔画、不修改旧的掩膜或分类。它同时保存当前正在画的那张与此前访问过的图片。旧版四个属性原样保留；新版缺少的来源、物体类别和编号另作兼容补充。备份在内存中整理成功不等于已经写入磁盘，请检查下载文件。

## 放大后工具栏仍在旁边

点“放大标注 · 工具栏在旁边”。画笔、背景／擦除、不确定、撤销、笔刷粗细与时期切换固定在图旁边。滚轮围绕鼠标放大；空格拖动或鼠标中键平移；Esc返回普通视图。左侧其他设置可以滚动，常用画笔区域保持可见。

每期都在完整RGB自己的原始像素坐标上画。切换T1—T4不会改变其他时期的标注；“下载本期原始RGB”保存原始PNG字节。小图坐标仅用于迁回旧笔画和定位核对，不提前决定新训练集。

T1新画的根固定为已有基线根；后期的来源与持续／首次可见／延伸状态分开保存。导入的旧分类保留，不擅自改写。第一次显露、遮挡、褐变或未观察到都不能单独证明新生或死亡。

## 保存与后续裁剪

Ctrl+Z撤销一笔；Ctrl+S下载全部项目JSON。支持本机自动草稿备份，但移动文件、换浏览器或清理缓存后不能依赖它，**请另外下载JSON**。需要时点击“恢复本机自动备份”；这不会自动把备份当作已完成人工复核。导入原文件全文会保留在项目archives中；冲突保留当前已标值并报告，不覆盖你的现有像素。

四期整图标完并实际复核后，再按空间位置裁小图、划分训练／验证／测试；同一位置的四期进入同一集合，避免跨期泄漏。包内脚本保留了坐标和所有属性层的裁剪功能；默认拒绝把未复核草稿当作训练标签。只有明确完成整张检查后，未画的64才可在训练导出时转为背景。

未收到你的旧页JSON前，不能声称已经替你保存或核验实际8张。浏览器检查用的是另行构造的测试笔画，不是你的标注，不代表根系识别准确率。当前没有模型训练或新的Dice等结果。
