# 原版标注页：固定侧栏与60倍缩放

本次只更新你原版annotate.html的操作界面。图片与标注方式沿用原版，不带此前的预填标注，也不导入旧标注。你可以重新开始。

- 画笔、分类、擦除、撤销、粗细和缩放固定在图片旁边。
- 输入倍率、滑条或预设按钮可放大至60倍。显示放大不会生成新的拍摄细节或修改原图。
- 切换图片或用“本窗T1—T4”切时期，保持倍率和正在看的原图局部位置。
- 普通滚轮移动视野；Ctrl+滚轮缩放；按空格拖动或点“平移／拖动图片”。选回画笔或分类会退出平移。
- 原版导出按钮和分类保存方式保留；切图保留本次打开页面里的笔画，关闭前仍需导出。

单独网页文件位于仓库docs/index.html，图片在docs/images，按选择加载。离线备用ZIP只含可直接打开的annotate.html和本说明；如果仍使用原来的file:///地址，把ZIP内annotate.html替换原文件后刷新即可。界面更新脚本另存legacy_zoom60_patch.js。

浏览器操作检查通过不代表根系识别或分割精度。此前手工标注是否保留由你自行决定；本更新不会主动清除已打开旧页面内的标注数组。
