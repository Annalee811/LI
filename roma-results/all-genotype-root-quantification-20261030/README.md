# 三种质根长与时序分类统计

本批次实际完成根系分割 63/66 张，时序推理 17/18 个观测单元。所有数值来自真实冻结模型前向推理，没有重新训练，也没有补造缺失图像。本数据包的状态以 summary_status.json 为准。

## 表格

- Genotype_root_lengths_and_temporal_rates.xlsx：中文种质平均表、英文平均表、逐观测单元明细和方法说明。
- 根长_种质平均.csv：T1–T4逐种质算术平均根长。
- 时序类别根长占比_种质平均.csv：T1–T2、T2–T3、T3–T4逐种质三类根长占比。
- Root_length_details.csv / Temporal_rates_details.csv：逐观测单元、原始管号、缺拍状态和配准复核标记。

每个种质按用户要求设6个观测重复，先逐单元计算后求算术平均。保留原始管号及位置映射，不将同管不同位置声明为独立生物学重复。本表仅作描述性汇总，未进行显著性检验。

## 根长

冻结的V35 U-Net（验证选择第77轮，阈值0.5）处理完整RGB图像。宽度统一2550像素，保持纵横比，以256×256窗口、192像素步长和Hann加权重建概率图。不对掩膜增粗、删小连通域或修改宽度。根长为骨架中唯一8邻接边长度之和，横竖边长1，斜边长√2；存在正交桥接时不重复加入斜边。

物理标定尚未确认。毫米列留空；请确认完整扫描宽度及是否横向裁剪，不能把导出的100 dpi当作CI-600扫描标定。

若确认完整扫描宽度为215.9 mm，则每个2550像素宽归一化像素对应215.9/2550 mm，根长毫米值为像素根长乘以该比例。该条件式不作为已确认标定值使用。

全图总根长来自完整扫描图；时序占比来自配准后共同观测区域。二者空间范围不同，不能直接把全图根长乘时序占比当作对应类别的全图根长。

## 时序占比

使用冻结V66 U-Net时序头（第37轮）及V90的已学习ConvLSTM、GAT、局部修正器、连接配对器和结构一致性模块，针对每个新序列重新构图。局部器选择第100轮、联合模块选择第78轮。原训练均值和标准差冻结，阈值来自原验证集，不利用新区域人工标签。B3特定手工复核掩膜不移植到其他区域。

共同观测区保持T1坐标尺度。超过原模型2541×1108工作尺寸的区域采用重叠分块推理，中心优先拼接；只作空间无效区填充，不补造缺失日期。各共同观测带互不重叠，汇总时不重复计算根长。

颜色：持续紫色，新生绿色，延伸黄色；T1蓝色仅表示初始根系，不将首期根系强行分为三类。类别图编码0背景、1持续、2新生、3延伸、4初始根系。

新生/持续/延伸占比 = 当前相邻期共同观测区中该类别骨架根长 ÷ 三类骨架根长之和 ×100%。三类合计100%。这里的“率”是长度组成百分比，不是每日生长速率，也不是以此前一期根长为分母的存活概率。种质平均为各有效观测单元百分比的算术平均，不按根像素数加权。

只把真实拍摄的日期送入ConvLSTM。缺拍T3时不伪造T3，也不输出T2–T3或T3–T4的零值。缺拍序列的彩色图使用上一真实观测期作为条件，不代表缺失相邻期的时序结果。现有相邻拍摄对数：0353为6/6/6，A017为6/4/4，Q1为4/3/4。若源文件暂未恢复，已拍摄对数与已处理对数仍分别列明。

## 方法复核与继续计算

methods中的脚本对应本次实际推理及汇总，沿用既有LI和Temporal-segmentation-model工作区、源图、配准几何及权重；本结果包不另行复制原始图像及模型权重。脚本顶部工作区路径用于定位这些明确依赖，在其他机器需设置为相应路径。处理顺序为audit.py、binary.py、freeze_inference.py、temporal.py、summarize.py、report.py。binary.py和temporal.py保留已完成的实际输出，可在补齐源图后继续计算，不能把缺失状态替换为零。物理标定确认后，写入calibration.json的full_scan_width_mm及标定来源，再运行summarize.py和report.py即可更新毫米列，无需重新训练模型。
