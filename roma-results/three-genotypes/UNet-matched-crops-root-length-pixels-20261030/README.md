## 方法与范围

任务范围：固定模型进行根系与背景二元分割，统计裁剪配对视野T1、T2、T3、T4的像素骨架根长。

模型：原V35 U-Net，100轮训练后按验证集选第77轮，阈值0.5。CPU FP32，256×256窗口，192步长，Hann加权重建。

输入：从原始RGB和冻结配对裁剪参数重建，重建PNG的SHA256与当前有效数据清单中已裁剪配对图完全一致。

重复：每个种质6个配对序列各算一次描述性汇总重复；先逐重复计算，再对有效重复求算术平均。保留源文件夹映射；仅描述性平均，不做独立重复显著性检验。

像素根长：与既有根长评价一致：对二元根掩膜骨架化；唯一8邻接边横竖长1，斜边长√2；存在正交桥接时不重复加对角边；孤立骨架像素按1像素计。不是根像素面积。

视野尺度：每个配对序列沿用自身的参考像素网格，同一序列四期坐标一致；不同序列裁剪面积和原始采样尺度可能不同。这里是裁剪视野的像素根长，未按面积或物理尺度归一。

多条观测带：拼接图的24像素人工白色分隔带不是观测区域，根掩膜和根长均排除该区域；各有效观测带相加，不跨分隔带连接。

掩膜处理：不增粗掩膜，不删除小连通域，不为缺失时期补图。保留模型阈值输出并排除人工分隔带。

缺失值：NA不代表0。未拍摄与源文件不可用分别列明；每期均值只使用该期实际完成的图像，有效重复数另列。

输出图像：root_mask.png为原裁剪尺寸的二元掩膜；skeleton.png为测长骨架；roots_on_white.png保留根系原始RGB颜色；overlay.jpg仅为缩略预览，不参与测长。

模型估计：这些是冻结U-Net在当前裁剪视野上的预测根长；未提供逐图人工真值，因此不附加本批图像的Dice或准确率。
