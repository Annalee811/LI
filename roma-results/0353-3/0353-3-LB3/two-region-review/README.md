# 0353-3-LB3：两段共同区域复核结果

完整原图复核发现两段真实的区域对应。A区把T1/T2上中部的细根、斜向根束及土层结构对应到T3/T4下部；B区把T1/T2下部的根系与土层对应到T3/T4上部。此前只保存A区一个连续矩形，遗漏了B区，不能将旧裁剪面积视为全部重合面积。这里只记录观察到的两段偏移，不推定采集设备的周期机制。

- A区四期独立裁剪均为2538×828像素；B区均为2538×769像素。两段合计覆盖原始T1画面的69.93%，是几何可观察覆盖，不是所有点可靠匹配的比例。
- 两段拼接的独立RGB均为2538×1621像素，含24像素白色分隔带。白带不是实测像素，接缝两侧不可当作连续根系；对应掩膜在白带处为0。
- 每段只用整体等比缩放、旋转、平移，从原始RGB单次采样。T1两段与原图裁剪逐像素相同；不改色、不做弹性扭曲。
- A区三组相邻自动点验证中位数为1.82、2.44、1.99个T1像素，T2/T4独立路线与连续链差异0.92像素。但直接T1/T4路线差异6.65像素，未通过5像素路线规则，A区仍需目视复核，不能声称逐点连续配准全部通过。
- B区三组相邻自动点验证中位数为1.82、1.82、1.99个T1像素；T1/T3、T1/T4、T2/T4独立路线差异分别为0.66、1.52、0.71像素。新增完整RoMa T1/T4提供569个内部支持候选，与B区模型的中位差异2.07像素。

没有人工标志点，真实TRE未评估。根系局部对照是同一观察窗的原色放大，不是逐根身份、新生或死亡的判定。自动点验证依赖筛选后的特征点，路线一致性和RoMa置信度均不是独立真实精度。原图中更低分辨率时期的拍摄细节不会因统一尺度或600 DPI增加。下载ZIP仅含结果图片；脚本和审计证据另存于仓库。
