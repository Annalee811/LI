使用T1→T2→T3→T4相邻结构关系定位，三组自动点验证中位数分别为1.82、2.59、1.95个T1像素；独立T2/T4路线与连续定位差异中位数1.01、95百分位2.22个T1像素。T1与T3/T4直接匹配较少，不视为通过直接匹配验证。共同横向区域较窄，由四期实际取景范围决定。

共同范围是自动结构定位结果，不是逐条根身份或新生、生长、死亡的确认。几何可观察区域与可靠点对应不同，局部变化不通过自由变形消除。点误差与区域模型稳定性分别记录；空间分块验证依赖筛选后的描述子对应点，不能当作人工TRE或独立真实误差。没有人工标志点，真实TRE未评估。统一像素尺度和600 DPI不会增加原始拍摄细节。ZIP只包含5张PNG；脚本与审计记录单独保存在analysis-scripts。
