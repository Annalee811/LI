# 0353-1-B3 同一区域定位与统一尺寸裁剪

四期齐全，以T1为基准，细框标出四期共同观察区域。保留新生、延伸及根系/土壤的局部变化。定位图显示原色原图；独立裁剪图只使用整体等比缩放、旋转和平移统一到T1尺度，不使用局部弹性变形。四张裁剪图均为2382×1028像素，原色无标注PNG。

ZIP内仅包含5张PNG图片。T2/T3原始分辨率较低，统一尺度不会创造未采集的细节。区域定位结合原始输入SHA256核验的已有RoMa匹配与完整原图、多尺度结构验证；未提供人工标志点，定位属于自动验证，不表示逐条根的身份或生死已识别。
