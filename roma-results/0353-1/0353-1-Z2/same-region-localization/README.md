本位置四期取景上下偏移较大，共同区域较窄，主要落在持续可见的土层结构上。原先T1/T2 RoMa无可靠匹配，新的直接自动验证中位误差3.81个T1像素，未达到3像素规则；因此使用验证更强的T1/T4、T2/T4、T3/T4结构关系间接定位。独立T2/T3路线与该定位中位差0.58个T1像素。T4仅作为对应关系中间参照，输出标准仍为原始T1。

该范围是自动结构定位，不能认定为逐条根的连续对应；建议重点目视核对T1/T2。没有人工标志点，真实TRE未评估。T2/T3原始分辨率较低，统一尺度与DPI不会增加未采集的细节。ZIP仅包含定位图与4张独立PNG。
