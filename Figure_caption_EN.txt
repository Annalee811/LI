Figure. Deep learning with topology-constrained decoding for temporal root phenotyping in minirhizotron images.

(A) Registered RGB observations from a common field of view at T1-T4 undergo shared frozen preprocessing to obtain U-Net root-region masks, V66 pairwise temporal priors, root nodes, graph edges and frame maps. (B) A shared frame CNN supplies the ConvLSTM temporal encoder. ConvLSTM and GAT form one joint module, with learned identity gating inside GAT message passing. Temporal context is sampled at root nodes and fused with node features; the neural heads predict class refinements, root identity associations, root state and junction-pair scores. Class, identity, junction and root-state supervision is used during training only. (C) Fixed neural outputs and learned features guide sequential root-axis and junction decoding. Axis constraints combine cross-period correspondence with whole-axis state consistency; junction constraints regulate branch/crossing ownership and local class compatibility. These decoding steps combine learned evidence with explicit geometric and temporal rules. (D) The implementation retains persistent (P), new (N) and extending (E) categories internally; final two-class outputs map N to new roots and P plus E to existing roots. The pipeline also exports axis ownership IDs and confidence flags. RGB panels are actual same-field B3 crops; the T2 overlay uses a cached Full-model prediction after both decoding stages (seed identifier 20261123). Network, root-axis and junction icons are schematic. The scale bar is 50 native pixels. This is an offline sequence workflow: later observations may inform earlier states.

Important interpretation: this schematic describes the implemented workflow and does not by itself establish component benefit, independent accuracy or biologically correct instance attribution. The current two-class presentation is obtained by merging the original three-class outputs; it is not a newly trained two-class neural head. The shared frame CNN is retained in the joint-module ablation. Root geometry remains fixed during the illustrated structural decoding.
