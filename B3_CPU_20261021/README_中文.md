# B3 三模型训练交付

最优候选（仅验证集选择）：changeformer。

训练范围为单个 B3 点位的四时期上部 ROI，使用用户最新人工标注原样快照。四期 TIF 为本范围综合展示，不是完整相机视野或其他点位结果。

三个模型都从随机初始化训练；本包记录各自权重、损失、验证选择、锁定测试指标和完整代码。训练轮为24样本抽样轮，完整训练行数48；不能把抽样轮数当完整数据遍历轮数。精确轮数和处理样本量见 history/result。

所有模型采用相同的验证集决策乘子网格调整，以缓解稀少类别漏检；不使用测试标签选择乘子，也不宣称乘子分数为校准概率。原始未调整指标另存，模型权重没有因乘子调整而重训。

采用384原始像素切片，训练/验证/测试先按空间划分，64像素隔离带；输入像素跨分区重叠为0。同一区域四时期始终同分区。空间分区仍可能包含同一长根的不同段，不是独立管组评价。其他微根管没有在本任务中被自动预测或当作真值。

输出类别：0背景、1持续、2新出现、3根尖延伸、255不确定；T1仅基线。颜色：紫=持续，绿=新出现，金=延伸，蓝=不确定；实例颜色另存。原始预测和保守身份结果分开保存。交叉区域拒绝归属，不强行串根；所有生物学身份均为待验证候选。没有人工实例真值，因此不提供虚构的ID准确率/合并错误率。“每像素唯一ID”仅为结构约束。侧根父子关系未获人工确认。

Siamese U-Net为上传ChangeFormer仓库中的FC-Siam-conc；STANet复用原ResNet18/PAM并适配四类任务头；ChangeFormer V6保留原编码器、解码器宽度64。它们是公开源码的根系时序任务适配版本。未使用旧B3权重，未配准，未覆盖旧实验。

## 下载内容
- four_period_composite.tif：四期原生分辨率综合图，上排时序类别、下排候选实例身份。
- four_period_layers.tif：源RGB、原始类别、保守类别、不确定及uint32实例ID的多序列TIF。
- paper_figures.zip：PNG/PDF论文候选图片、图注说明和指标表。当前结果不代表已达到发表或部署精度。
- all_results_weights_scripts_data.zip：完整代码、源码来源与许可证、原样标注、RGB/标签与切片索引、配置、环境锁、三模型best/last检查点、日志、预测、指标与本报告。
- download_index.json：各交付文件大小、SHA256、用途与训练数据索引。

复现实验及对其他已配准微根管的推理命令见 code/README.md。训练检查点可恢复优化器、调度器和随机状态。建议首先审阅测试指标和交叉不确定图，不能仅凭整图视觉效果判断迁移可靠性。
