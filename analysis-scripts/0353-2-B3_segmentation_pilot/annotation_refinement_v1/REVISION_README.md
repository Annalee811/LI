# Four-period revised root annotations on original RGB backgrounds

四期完整上半部分分别保存：原始RGB、原始人工掩膜、修订根系掩膜、修订RGB叠加图、原人工RGB叠加图、新增根像素掩膜、未确认分歧掩膜。原始RGB尺寸2541×1108px，颜色与原像素完整保留；叠加图为单独文件。root255/background0/uncertain128。

修订以原始人工根笔迹为基础，参考前一轮U-Net及RGB可见管状结构，补充窄标和漏标位置，并保留编辑记录。没有把土壤遮盖处的根臆测为已确认连续根，也没有把所有水珠边缘自动接受为根。原始人工标注没有覆盖写回。

这是模型辅助修订参考，不是独立人工真值。尚存的宽度、细根和水滴误差需结合RGB复核。所有原笔迹保留；修订主要是补充，无法保证逐像素无误。未确认分歧掩膜不是已确认错误或死亡根。

训练块的修订逐块独立执行；四期同一坐标同组。训练200张原像素视图，验证20张、内部测试24张。新增训练窗口仅在训练附近平移12px并排除所有验证/测试像素，训练窗之间有重叠，不能当200张独立采集图像。原始验证/测试掩膜保持不变；它们负责选模型及主要准确性评估。修订参考的一致性需另列，不能冒充独立人工准确率。

原始人工JSON与其时序属性在训练数据包中保留。这里的修订是根/背景二分类，不重写新生、持续、延伸属性，不纳入死亡。完整参数和旧U-Net权重哈希见provenance.json；逐幅/逐块新增像素统计见revision_log.csv。
