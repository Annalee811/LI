# Full-field U-Net temporal reference continuation (V21)

This run creates a new four-upper-frame proposal from the fixed V19 U-Net root
geometry and structured temporal predictions. The source `(6)` JSON and its
class maps are preserved. No random label error is introduced to control a
metric. Only explicitly flagged, weakly supported crossing pixels are left
temporally untyped. The proposal awaits human review; it is not an independent
manual reference.

## Inputs and execution

Use the repository root as the working directory. `--previous` must contain
the V19 paired/spatial manifests, the four native RGBs, original class maps,
three temporal-head checkpoints, frozen train-only routers, geometry caches,
and RGB/root-derived feature caches. `--roots` must contain the unchanged
three root/background checkpoints, four root masks and probabilities per model.
Inputs are not downloaded or regenerated by this continuation script. Native
RGB hashes, checkpoint hashes and source JSON hashes are recorded in the run.

```bash
PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=3 MKL_NUM_THREADS=3 \
.venv/bin/python -B \
analysis-scripts/0353-2-B3_segmentation_pilot/temporal_unet_aligned_v21/run_all.py \
--run results/B3_temporal_unet_aligned_v21_20261021 \
--roots results/B3_annotation_refinement_v1 \
--previous results/B3_temporal_current_annotation_v19_20261021 \
--progress results/B3_temporal_current_annotation_v19_20261021/data/selected_progress.json \
--epochs 16
```

Dependencies are pinned in `requirements.txt`. Legacy temporal head, loss,
metrics and geometry helpers are included under `legacy/`. The three frozen
root detectors are U-Net, DeepLabV3+ and SegFormer-B0. Their paired, 31-channel
temporal heads are continued in PyTorch; this does **not** retrain the three
root backbones end-to-end. DeepLabV3+ frozen binary outputs originated from
TensorFlow. Reused features contain RGB, root probabilities and geometry;
they do not contain annotation class rasters. V19 routing was learned on the
training region only and remains frozen.

Preparation is idempotent. Each epoch saves a resumable checkpoint with
optimizer, scheduler, augmentation RNG, sampler RNG, training queue and draws.
Completed training and predictions are reused. Previous run folders are never
overwritten. Symlinks to the immutable V19 caches avoid redundant 1.5 GB copies;
keep the previous input run accessible when moving this run.

## Labels and evaluation

Model rasters: 0 background, 1 persistent, 2 newly observed, 3 terminal
extension, 4 T1 baseline, 255 untyped/ignored. Editor temporal layer:
0 untyped, 1 new, 2 extension, 3 persistent, 4 baseline. Root geometry remains
present under untyped temporal pixels.

T1 is baseline; T2/T3/T4 refer to their immediate predecessor. The same
spatial split is retained across every date: 150/15/18 train/validation/test
adjacent-date pairs, from 50/5/6 spatial views. Training includes shifted
overlapping views; these are not independent biological samples. Death is
excluded.

The checkpoint and decoder strength are selected by validation **teacher
consistency**. Test agreement with the U-Net-derived proposal and agreement
with the preserved original annotations are reported in distinct tables.
Neither is an external independent accuracy estimate. Historical same-field
exposure applies; independently annotated external test images: 0. T1 is not
included in the three-class temporal Dice average. Scores are not guaranteed
to exceed any target. No deliberate annotation perturbation is used.

Candidate-axis decoding uses either a newly observed root, or a persistent
shaft with terminal extension. Each output pixel has one class. A geometric
axis is not a biologically verified root identity; ambiguous crossings remain
flagged.

`annotation_review/annotate.html` embeds four RGBs and the proposal for offline
editing (60x zoom, retained zoom on date switch, Ctrl+Z, JSON export).
`selected_progress.json` preserves the full original eight-entry source;
`active_progress.json` contains only the four revised upper entries;
`full_progress_compatibility.json` additionally retains all untouched older
entries. Revisions remain traceable in provenance and change masks.

`report.py` derives tables and figures solely from saved predictions.
`audit.py` checks unchanged inputs, editable JSON round-trip, typed teacher
agreement, categorical ownership, finite checkpoints, frozen root weights,
identical three-model sampling, and saved-confusion metric consistency.
