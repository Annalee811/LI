# 全系列共同区域与 RoMa 累计置信度复现

Python 3.12 / Linux。安装 `requirements.txt`，完整 RoMa 包源码放在 `vendor/romatch`。
模型权重由 RoMa 官方模型地址获取；已有 `TORCH_HOME` 缓存可直接使用。
运行 `bash reproduce.sh /path/to/output`。自动检测 CUDA；本次使用 CPU、完整 outdoor RoMa、560 粗分辨率、864 输出分辨率、双向预测。

## 面积定义

每段 T1 矩形按像素边界映射到该期原图，裁到原始画布后计算多边形**并集面积**。
共同面积比例 = 共同区域在该期原图中的并集面积 / 该期原图完整宽×高。
相似变换的尺度平方、旋转、重复覆盖与接缝均按这一口径处理。
即使 B3 仅交付上半幅，其分母也仍是该期**完整原图面积**，并未改成上半幅面积。
原生掩膜为像素中心栅格化；连续多边形面积与栅格像素数允许边界量化差异。
未建立定位时共同面积记为未确定，不能把未定位误说成真实重叠为零。

## 累计置信度及有效掩膜

在已定位、统一到 T1 像素尺度的独立拼接 RGB 上，重新运行完整 RoMa。
这样可避免原图各段上下换位时，全幅 RoMa 选择另一个重复区域、使置信度与交付裁剪不对应。
以 T1 像素为查询点，沿各相邻实际观测时期的 RoMa 对应场逐步传送坐标；
每一步取源坐标的正向置信度与其预测目标坐标的反向置信度之较小值 c。
T1 基准为 1；逐期累计 C = 沿这条稠密对应链的各边 c 的乘积。
路径离开本观察段时置零，不可跨白色接缝或跳到另一段。
缺少 T3 时使用明确标示的 T2→T4 观测边。
同时保存瓶颈置信度 min(c)，便于不同序列长度间参考；C 不是已校准概率。
这是以所选区域定位为条件的对应置信度，不能反过来当成定位矩阵的独立验证。
白色接缝不计入置信度统计或有效区域；重定位仍依赖另行保存的 RoMa/RootSIFT 结构证据。
`*_float32.npz` 为原始数值，16 位 PNG 值 /65535 得到置信度，预览采用统一 cividis 0–1 色标。
既保存拼接坐标的置信度，也保存原始 T1 坐标的 16 位置信度图。

有效重叠掩膜 = 几何共同区，且所有累积观测边同时满足 c≥0.5、
每步 RoMa 对应位移≤15 个原生 T1 像素、正反向循环误差≤10 个原生 T1 像素，且路径未离开本观察段。
上述置信度筛选掩膜另外以 `confidence_filtered_correspondence_mask` 明确命名，专用于对应质控。
做根系生长变化分析时，使用 `effective_common_observation_mask.png`：它是几何共同观察区，
包含真实的新生/移动根系；不能以低对应置信度为由将生物变化像素直接删除。
低置信度面积为共同区内 C<0.5 的比例，接缝不参与分母。
根系生长、土层移动、反光和重复结构可使几何定位成立而逐点支持较低。
几何面积不代表配准准确率；没有人工标志点，未报告人工 TRE 或根系身份识别准确率。

## 文件与验证

`render_results.py` 生成独立 RGB、各期原生共同区域掩膜、定位总览及累计质量图。
`verify_results.py` 重算全部区域 RGB，逐像素比较，校验原图字节、尺度平方和区域并集、接缝排除、
累计浮点置信度的 16 位编码，以及有效/低置信度掩膜的像素数。
`summary_figure.py` 输出面积及有效点支持汇总图；图上空白/灰色是缺期、参考期或未定位。
`package_results.py` 输出一个 ZIP；不重复打包已拼接的各段 RGB 副本，原图、独立拼接 RGB、
区域坐标、全部掩膜和数值置信度均保留。脚本本身仍可重建各独立区域 RGB。
`file_manifest.json` 与包外 SHA256/CRC 校验记录用于完整性检查。
没有 Word 文件；不会修改或覆盖原始输入、人工标注、训练模型或既往历史包。

总包对累计C保留逐位一致的float32 NPZ、原始T1坐标16位PNG、拼接坐标彩色预览及带色标PDF。
为省去重复存储，瓶颈置信度保留均值，其完整矩阵可用脚本重建。工作目录仍保留全部辅助输出。
中文定位总览使用Noto CJK字体（Ubuntu包fonts-noto-cjk）；OpenCV需libgl1和libglib2.0-0。

Q1-3-Z3 未建立连通 T1 的对应：保留三期原图，共同面积为未确定。
另保存有结构支持的 T2/T3 局部 RGB 与掩膜，明确采用 T2 为参考，且不纳入全序列统计。
