# 0353-1-Z2: user-guided root-region localization recheck

Reproduce with `PYTHON=/path/to/python bash reproduce.sh /path/to/originals /path/to/work`. Install the pinned requirements first. The standalone archive includes the exact RoMa upstream source and its license in `scripts/support/vendor`, the common rendering/inference helpers, and model provenance with checkpoint SHA256 pins. Official Torch Hub weights are reused or downloaded through RoMa; the ~1.6 GB weights are not duplicated in the result ZIP. CUDA is detected automatically; this run used CPU.

The original four photos are pinned by SHA256. Broad root-layer search rectangles were inferred from the user's red boxes. RGB is always sampled from the original-color photos. Only a global uniform similarity is allowed per period; there are no elastic or dense RGB deformations. T1 is an exact native crop, all output RGBs use T1 pixel scale, and native unresampled bbox crops plus geometric polygon masks are also saved.

Search first used full RoMa on original-color root bands, supplemented by multi-mode RootSIFT. The original-region neural fits support T1/T2 and T3/T4. T2/T3 did not gain enough reliable point matches, including tighter CLAHE crops and a direct T1/T3 diagnostic. Its fallback is explicitly **coarse and unverified**: masked, elongated ridge-pattern correlation within the user-supplied root bands selects a translation near +692.22 native T3 pixels in y, with a distinct correlation peak. Ridge cues are not verified root masks and do not prove root identity. This fallback is not counted as a successful RoMa point registration.

The candidate T1 common rectangle [26,438,2340,1308] gives 2314×870 pixels. These areas are conditional on the saved localization, not independently validated biological common areas or registration accuracy. The whole four-period sequence remains marked for review. Only this position is written; all other locations and the previous all-series archive remain unchanged.

After fixing the window, full RoMa runs on the actual aligned original-color RGB for per-edge and cumulative QC. Confidence is conditional on the pose and is not calibrated probability or independent validation of that pose. Coordinate paths are transported along all three adjacent dense fields; cumulative confidence is the product of the minimum forward/reverse confidence at each step. The 0.5 threshold, 15 T1-pixel displacement and 10 T1-pixel cycle limits identify high-confidence correspondences. Low cumulative confidence means product <0.5. The first two transitions are weak in the common-window test; no pixels pass the strict full cumulative chain. The geometric observation mask retains the whole candidate root window and is separate from the confidence-filtered correspondence mask.

Tables retain native image dimensions, exact similarity-area ratios, original-view sampled match counts, fitting anchors, conditional descriptor checks and conditional neural spatial cross-validation. Dense samples are spatially correlated and are not independent manual landmarks. No manual landmark TRE is available. The point-supported adjacent-pair fraction (2/3) is a search/pose-evidence statistic, not manual success or full-chain accuracy.

All preprocessing and diagnostics are retained. The script verifies original file hashes, exact RGB sampling, uniform transformations, native-area determinants, inference input hashes, finite monotone cumulative confidence and mask consistency. Figure names state what is displayed. The full float32 fields are retained even when no vectors pass the preview threshold; previews never hide or improve reported metrics.
