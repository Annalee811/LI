# Q1 scientific region-processing audit

Original RGB inputs are from the v-change-data release. The input inventory distinguishes available, missing, skipped and unlocalized periods. Hashes are verified. Put originals under input/raw/V-变化/ within this evidence root to reproduce.

The parent analysis-scripts contains export_Q1_same_region.py, export_Q1_partial_review.py, search_Q1_region_structures.py, collect_Q1_roma_region_candidates.py, collect_Q1_orientation_trials.py and existing generic collectors/helpers. Standard export accepts --root and --position. Q1-2-Z2 requires --allow-no-extra-route and remains a candidate; this does not turn absent corroboration into a passing test. Partial review export accepts --root and --position for Q1-2-B3/Q1-3-Z3.

Raw full RoMa (560/864) was run on consecutive available periods; extra T1/T4 (Q1-2-B3) and T1/T3 (Q1-3-Z3) were checked. Detector-only contrast normalization, CLAHE/blur descriptors at 1000/1600 widths, ridge/crack/gradient structure searches and bounded 0/90/180/270 camera-orientation trials (336/448) preserve failed outcomes. Rotation trial points are returned to original target coordinates. Preprocessing is only for matching, never applied to saved RGB. Alternative contrast/orientation caches remain separate from raw model candidates. Their internal confidence is not ground truth.

Q1-1-B2 and Q1-2-Z3 have spatially supported structure relations and unused-route corroboration. Q1-2-Z2 has supported T1/T4 and T3/T4 structure relations but no eligible unused route; it is labeled candidate. For Q1-2-B3 only internally supported neural T1/T2/T3 hypotheses are rendered as unverified candidates; T4 has no supported location and is saved unchanged at native size, with no invented crop. Q1-3-Z3 has no reliable T1 relation; all RGB images remain native and unregistered, and no T1 common rectangle is invented. Partial diagnostics are not full-sequence registration success. Q1-1-B3 has only two periods and is skipped under the user rule.

Conditional descriptor spatial CV, block-model sensitivity and neural confidence/cycle are distinct from manual landmark TRE and from confirmed root identity. Actual roots and soil changes are preserved; no biological new-root/death classifications are inferred. The 3px point-pass and 5px route rules remain recorded; output integrity passes do not imply registration quality passes. Cropped T1 pixels exactly match originals; supported RGBs use one global similarity sampling, unlocalized RGBs retain original pixels. Root structure is a matching proxy, not segmentation. Full prediction caches remain in local execution results and can be regenerated by the collector; do not overwrite hash-verified evidence for a fresh experiment.
