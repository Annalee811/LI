# 原统计表对应的全部微根管分割图片

本包对应用户指定的 All_microtube_root_traits.xlsx（固定提交8b4fdb81b5938720e263d802426745c982c4479c，SHA256 ea74bf1853766e51fa3b30546d6893032e57e50ea991514c2735182a6fdb0e52）。全部图片直接取自该提交发布的三个系列原始结果包，不重新训练、推理、配准、测长或修改图像，不改写原表的数值或缺失状态。

## 数量与模型

18个观测序列，嵌套于8个源管号；63张有效影像（0353:24，A017:22，Q1:17），对应441个图片文件。441是不同输出类型的文件数，不是独立影像数。模型为既有V35 U-Net二值分割（选择第77轮）与V66 U-Net时序头（选择第37轮）。这是原统计表的模型版本，不是V90结果。

72个预期时期单元中，6个未采集时期和3条源结果不可用记录均保留缺失；没有用其他目录的影像补算。原表对应40组有效真实相邻时期。部分缺失期后的已观测影像仍有供显示的跨缺失期类别图，但这些长间隔结果不计入真实相邻时期统计。详见 Frame_status.csv 和各源目录的 Cross_gap_comparisons.csv。

## 文件夹

V35_binary/种质/观测编号/：每条有效影像有4种输出。
- Tn_overlay.jpg：根系分割叠加于原背景的既有JPG预览。
- Tn_root_mask.png：原裁剪尺寸的二值根系掩膜。
- Tn_roots_on_white.png：保留根系原始RGB、白底去背景图。
- Tn_skeleton.png：既有测长骨架图。

V66_temporal/种质/观测编号/：每条有效影像有3种图片及测量记录。
- Tn_temporal_overlay.jpg：持续/新生/延伸类别在原背景上的既有JPG预览。
- Tn_temporal_on_white.png：白底时序类别图。
- Tn_classes.png：原尺寸类别编码图；0背景、1持续、2新生、3延伸、4基线、5无前期观测的未分类根。
- Tn_temporal_measurement.json：已有时序测量记录。

原背景JPG叠加图是源包提供的缩略预览；保留原生尺寸的是PNG掩膜、类别图及根系提取图。本次不重新编码、不放大、不额外锐化、不重绘这些文件。归档结果对应配准后的匹配裁剪视野，不是完整未裁剪相机扫描图。不同观测序列的视野面积和尺度可能不同，未经标定不能将像素长度解释为毫米。
