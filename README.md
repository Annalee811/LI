# Materials and Methods — bilingual revision 2

Expanded, paired Chinese/English manuscript methods for the Elymus sibiricus minirhizotron study. The main text now contains architecture, optimization, temporal identity refinement, length-trait and evaluation definitions with 26 editable equation groups per language. Essential metadata and provenance are retained in a six-page supplement; lengthy duplicate methods and commands have been removed.

- Materials_and_Methods_CN_EN.docx: Chinese main text, English main text, compact supplement and references, separately paginated; 24 rendered pages.
- Supplementary_Information_CN_EN.docx: standalone compact supplement; 6 rendered pages.

The files remain drafts requiring author completion of 31 genuinely blank experimental metadata values in Table S1 and the short verification notes. Source inspection and writing did not rerun registration, training or inference. This new branch preserves earlier documents and project branches.
